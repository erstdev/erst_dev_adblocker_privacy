Приватная политика erst_dev_adblocker

Дата последнего обновления: 29 сентября 2026 года

Кратко

Расширение erst_dev_adblocker не собирает, не хранит и не передаёт персональные данные пользователя. Все настройки хранятся локально в браузере.

Какие данные хранит расширение

Расширение хранит в локальном хранилище браузера (chrome.storage.local) только следующее:

  • Флаг «включено/выключено» — работает ли блокировка в данный момент.
  • Белый список сайтов — список доменов, на которых пользователь отключил блокировку.

Эти данные:

  • создаются и изменяются пользователем через интерфейс расширения;
  • хранятся локально на устройстве пользователя;
  • не передаются на серверы разработчика или третьих лиц;
  • удаляются вместе с удалением расширения.

Какие данные расширение не собирает

Расширение не собирает:

  • персональные данные (имя, email, телефон);
  • историю посещения сайтов;
  • содержимое страниц, которые открывает пользователь;
  • учётные данные, пароли, cookie;
  • любые данные, которые можно связать с конкретным пользователем.

Сетевые запросы

Расширение не отправляет никаких сетевых запросов на серверы разработчика. Вся работа происходит локально.

Используемые внешние ресурсы:

  • Списки блокировки правил (EasyList, AdGuard Russian) скачиваются один раз при сборке расширения и упаковываются в сам архив. Расширение не запрашивает их в интернете при работе.

Разрешения

Расширение запрашивает следующие разрешения:

  • declarativeNetRequest — для блокировки сетевых запросов.
  • scripting — для вставки косметических стилей на страницы.
  • storage — для хранения настроек пользователя.
  • webNavigation — для отслеживания загрузки страниц.
  • tabs — для определения активной вкладки.
  • host_permissions: <all_urls> — для работы на всех сайтах.

Ни одно из этих разрешений не используется для сбора или передачи данных. Все они нужны для основной функции — блокировки рекламы.
